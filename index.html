projects

FinTrack Expense Manager

An interactive expense tracking dashboard incorporating custom finance modules and gamified budgets, developed for the VIT Void Hackathon (secured Top 5).

Key Learning: Designing quick, responsive finance components and pitching our 2nd review to judges at 2 AM!

Rural Preventive Health Portal

A preventive health awareness platform tailored for rural communities, focusing on women's health awareness and local hospital connectivity, built for Presidency University's National Hackathon.

Key Learning: Designing accessible user layouts for rural populations, and coding so intensely all day that we completely forgot to eat lunch!

Aadhaar & DBT Literacy Platform

An educational web service centering Aadhaar-enabled Direct Benefit Transfer (DBT) registrations to assist rural citizens in understanding government benefits, developed for Smart India Hackathon.

Key Learning: Structuring simple search tools for public benefit database systems and coding through a 36-hour sprint.

Smart Attendance System

A webcam-based automated attendance prototype utilizing face recognition technology to verify student identity and match records instantly, built during my first-ever hackathon.

Key Learning: Understanding camera image capture buffering and working within a team dynamic for the first time.

Titanic Predictor Model

Developed a machine learning model using the Titanic dataset to predict passenger survival. Explored data preprocessing, feature engineering, and classification techniques while learning how machine learning models make predictions from historical data.

Key Learning: Exploring classification techniques and understanding prediction algorithms.
